# 금빛과 재 — WACA 배틀그라운드

로블록스 **가장 강한 전장(The Strongest Battlegrounds)** · **주술 시네니건(Jujutsu Shenanigans)** 스타일의 전투 게임입니다.
노션 「WACA // 기밀 인물 도감」에 있는 자캐 두 명을 **무브셋(기술 세트) + 무기**로 만들었고,
가강전처럼 **플레이어는 자기 로블록스 아바타(R6)** 로 싸웁니다.

- 린 위안: 등에 목봉과 삿갓, 기술을 쓸 때 목봉을 손에 든다
- 칸자키 렌: 손에 카타나, 왼쪽 허리에 봉인선 10개가 새겨진 칼집

| | 린 위안 (WACA-21) | 칸자키 렌 (WACA-4) |
|---|---|---|
| 이명 | 금빛 귀환자 | 애시마크 · 회흔 |
| 스타일 | 봉술·장법, 버티고 흘려보내는 무예 | 발도술 + 회분 자원 관리, 원거리 참격 |
| 1 | 기형 · 금장 — 거대한 금빛 손바닥 | 무염박리 — 파고들며 발도, 회분 +2 |
| 2 | 유전 — 근접 공격·투사체를 받아 되돌림 | 회류반송 — 회분(최대 3) 소모 직선 참격 |
| 3 | 봉술 · 회천 — 3회전 휩쓸기, 띄우기 | 측면삭 — 지면을 스치는 참격, 넘어뜨림 |
| 4 | 천 번의 반죽 — 연타 후 목봉 마무리 | 회막 — 검은 분진막으로 시야 차단 |
| 각성 (G) | **심기체일 — 용의 전사**: 황금 용 외체 | **무염재단 · 전력 발도**: 회분 무한 |
| 각성 기술 | 용조 / 용권선 / 승룡 / 황금 용의 귀환 | 연속 반송 / 절단선 / 회막·사냥 / 10단위 최대 출력 |
| 대가 | 권능 종료 후 탈진 (영력 사용 불가) | 최대 출력 후 폐포 손상 (이능 사용 불가) |

![아바타에 무기를 든 모습 — 린 위안(목봉·삿갓) / 칸자키 렌(카타나·칼집)](docs/avatar_gear.png)

*(기본 R6 아바타에 장비를 붙여 렌더링한 미리보기. 실제 게임에서는 각자의 아바타 옷·액세서리가 그대로 보입니다.)*

프로필의 능력 원리·한계·대가(예: 렌은 칼로 벤 **비생체 물질**만 회분으로 바꿀 수 있고, 참격은 **직선으로만** 날아감 / 린의 《유전》은 **한 번에 하나의 힘**만 흘림, 권능 뒤 **탈진**)를 게임 규칙으로 옮겼습니다.
렌은 설정상 권능이 미각성이라, 각성은 “게임용 전력 모드”로 따로 만들었습니다. 그리고 로블록스 커뮤니티 규칙(담배 묘사 금지) 때문에 렌의 담배는 모델에서 뺐습니다.

## 바로 해 보기 (Roblox Studio)

1. `build/GoldAndAsh.rbxl` 을 Roblox Studio 로 엽니다.
2. ▶ **플레이**를 누르면 선택 화면에 **내 아바타가 각 캐릭터의 무기를 든 모습**이 나옵니다.
3. 혼자라면 왼쪽 위 **봇 소환** 버튼으로 상대를 부르거나, 광장 북쪽의 **훈련용 허수아비**(가운데 허수아비는 항상 막기)를 때려 보세요.
4. 싸우는 도중에도 왼쪽 위 **캐릭터 변경**으로 무브셋을 바꿀 수 있습니다 (마지막으로 맞은 뒤 5초가 지나야 함).

> 아바타 설정(R6/R15)은 바꿀 필요 없습니다. 서버가 각자의 아바타를 R6 로 변환해서 씁니다.
> 이미 게시한 게임을 이 파일로 바꾸려면: 파일 → **다른 이름으로 Roblox에 게시** → 기존 「금빛과 재」 선택.
> (예전 파일의 `SoundIds` 에 넣은 오디오 ID 가 있다면 새 파일에도 다시 넣어 주세요.)

### 조작법

| 입력 | 동작 |
|---|---|
| 좌클릭 (누르고 있기) | M1 4연타. 4타에서 Space를 누른 채면 **띄우기**, 공중이면 **내려찍기** |
| F (누르고 있기) | 막기. 맞기 직전(0.16초 안)에 누르면 **패리** |
| Q + WASD | 대시 (앞/뒤/좌/우). 린 위안의 앞 대시는 구르기 |
| 앞 대시로 적에게 파고들기 | **대시 타격** (주츠 시네니건처럼) — 맞으면 짧게 경직, 바로 M1 으로 이어 칠 수 있다 |
| 스턴 중 Q | 회피 (회피 게이지 100%일 때) |
| 1 ~ 4 | 기술 |
| G | 각성 (각성 게이지 100%) |
| Shift | 시점 고정 |
| H | 조작법 창 |

게임패드(R2 공격, L2 막기, B 대시, Y 각성, 방향패드 기술)와 모바일(화면 버튼, 기술 칸 터치)도 지원합니다.

### 한국어 / English

로블록스 언어 설정이 한국어면 한국어, 그 밖에는 영어로 시작합니다. 선택 화면 왼쪽 위와 게임 중 왼쪽 위 메뉴의 **🌐 버튼**으로 언제든 바꿀 수 있습니다.
캐릭터 소개·기술 이름·알림·킬 피드·머리 위 이름표까지 모두 바뀝니다. 문자열은 `src/shared/Locale.luau`(UI·알림)와 `CharacterDefs.luau` 의 `en` 칸(캐릭터 글)에 있습니다.

## 사운드 넣기 (선택이지만 강력 추천)

효과음 39개와 배경음악 4곡을 전부 직접 합성해서 `assets/sounds/` 에 넣어 두었습니다.
로블록스는 외부 오디오를 쓰려면 **업로드**가 필요해서, 업로드 전에는 로블록스 내장 소리로 대신 재생됩니다.

효과음은 **파일 하나(`sfx_sprite.ogg`)에 전부 이어 붙인 "사운드 스프라이트"** 입니다. 게임이 구간을 잘라서 재생하기 때문에, 업로드는 **총 5개**면 됩니다. (인증 안 된 계정의 월 업로드 한도 대응)

- 방법 A — Studio: `보기 → 에셋 관리자` 에서 `sfx_sprite.ogg`, `music_*.ogg` 4개를 가져오기 → 각 에셋 ID를 복사해 `src/shared/SoundIds.luau`(Studio에서는 `ReplicatedStorage.Shared.SoundIds`)에 붙여넣기
- 방법 B — 자동: [Open Cloud API 키](https://create.roblox.com/dashboard/credentials)를 만든 뒤
  `python tools/upload_sounds.py --api-key <키> --user-id <내 유저ID>` → `SoundIds.luau` 가 자동으로 채워집니다.

자세한 설명은 `assets/sounds/README.md` 에 있습니다.

### 가강전 느낌을 위해 넣은 것

- **물리**: 대시·넉백은 수평으로만, 유한한 힘으로 민다(예전처럼 무한한 힘으로 고정해서 벽·경사·다른 캐릭터에 닿으면 튕겨 날아가던 문제 수정). 위로 띄우기는 한 번의 발사로 자연스러운 포물선. **캐릭터끼리는 서로 통과**하고, 부서져 날아가는 파편도 캐릭터를 치지 않는다.
- **지형 파괴**: 맵의 건물·가판대·차·가로등·나무… **바닥을 뺀 모든 것**이 스킬과 날아가는 몸에 박살 난다.
  맞은 부분만 조각조각 쪼개져 진짜 구멍이 뚫리고(복셀 파괴), 떨어져 나간 잔해는 각자 화면에서 물리로 굴러다닌다(서버 부담 없음).
  칸자키 렌의 칼·참격에 닿은 물체는 잔해 대신 검은 재로 무너진다. 35초 뒤 원래대로 복구(그 자리에 사람이 있으면 비킬 때까지 기다림).
  - 평타·연타·대시 타격: 작은 사물만 / 평타 4타·기술: 판정에 닿은 건물까지 / 각성기: 크게
  - 회분 2 이상 회류반송·연속 반송·측면삭: 건물을 베어 가르며 관통. 약한 참격은 벽에 구멍만 내고 멈춘다
  - 황금 용의 귀환: 반경 60 돔 전체 붕괴 / 10단위 최대 출력: 앞쪽 125 스터드 일직선이 재로
- **벽꽝·벽 뚫기**: 크게 날아간 몸이 건물에 부딪히면 뚫고 지나가고(첫 충돌 추가 피해), 안 부서지는 벽이면 튕겨 나온다. 쓰러진 몸도 부수며 날아간다.
- **넉백 궤적**: 크게 날아가는 동안 몸에 바람 궤적.
- **각성 컷신**: 각성하면 카메라가 잠깐 캐릭터 정면으로 돌아 들어가고 레터박스 + 타이틀.
- **대시 타격**: 앞 대시 중 상대에게 닿으면 자동으로 돌진 공격 (린 위안은 장타, 칸자키 렌은 발도 베기).
- **화려한 타격감**: 강타마다 십자 섬광 + 방사형 충격선 + 바닥 충격파, 대시·넉백·각성 때 화면 가장자리 집중선, 처치 순간 폭발.
- **리더보드**: KO / Streak (3연속부터 전체 알림).
- **체력 회복**: 7초 동안 맞지 않으면 천천히 회복.
- 히트스톱, 화면 흔들림, 임팩트 프레임, 콤보 카운터, 가드 브레이크, 패리, 회피(스턴 중 Q).

### 어떻게 만들었나

- **애니메이션**: 로블록스 애니메이션 에셋은 업로드해야만 쓸 수 있어서, 대신 모든 클라이언트가 각 캐릭터의 관절(`Motor6D.Transform`)을 매 프레임 계산하는 **절차적 애니메이터**를 만들었습니다. 기본자세·달리기·공중 자세 위에 공격 모션을 섞고, 360° 회전 같은 동작도 풀리지 않게 보간합니다. 로블록스 기본 R6 관절(C0 가 돌아가 있음)에도 똑같이 맞도록 관절 회전을 보정합니다.
- **맵**: 「붕괴된 야시장 — WACA 사건 현장」. 가운데 석조 대련장, 북쪽 **林記麵館(린 씨네 국숫집)**, 남쪽 WACA 현장 정리 구역, 동쪽 거리, 서쪽 운하와 돌다리, 둘레의 고층 빌딩 스카이라인. 노을 조명. 상자·통·잔해는 **부서지고**, 렌이 칼로 베면 **검은 재로 무너지며 회분이 쌓입니다**.
  ![맵 평면도 — 가운데 광장, 북쪽 국숫집·야시장(허수아비 D1~D3), 남쪽 WACA 구역, 서쪽 운하, 동쪽 도로](docs/map_topdown.png)
- **이펙트**: 텍스처/메시 업로드 없이 파트·파티클·빛으로 만든 황금 용(마디 + 머리), 금빛 손바닥, 회분 초승달 참격, 분진막, 봉인선 점등 등.

### Rojo 로 계속 개발하기

```bash
rojo serve                      # Studio 의 Rojo 플러그인으로 연결해 실시간 동기화
rojo build default.project.json -o build/scripts_only.rbxl
lune run tools/build_place.luau # → build/GoldAndAsh.rbxl
```

`Config.luau` 의 `DebugHitboxes = true` 로 바꾸면 서버 판정 상자가 빨갛게 보입니다.
